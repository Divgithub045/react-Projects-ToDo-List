# Basic Counter Website Using useState() React Hook 
A simple React project demonstrating the use of the `useState` hook to build a functional counter application.

---

- **Increment**: Increase the counter by 1.
- **Decrement**: Decrease the counter by 1.
- **Reset**: Reset the counter to 0.

## Installation

1. Clone the repository
2. cd into your project
3. npm install
4. npm run dev
5. Open the app in your browser at the given path (generaly localhost:3000 / localhost:5173)
